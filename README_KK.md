# Профориентация 9 ЖББМ — №9 жалпы білім беретін мектеп (v0.4)

Бұл нұсқа — қазақ тіліндегі интерфейс және браузерде орындалатын кәсіби қызығушылық сауалнамасы бар демонстрациялық прототип.

## Жаңа мүмкіндіктер
- Оқушы кабинетінен 12 сұрақтық кәсіби қызығушылық сауалнамасын ашу.
- 6 қызығушылық бағыты бойынша бастапқы ұпайларды есептеу.
- Нәтижені осы браузердің localStorage қоймасында сақтау.
- Сауалнама толық аяқталмайынша нәтижені есептеуге жол бермеу.

## Маңызды шектеулер
- Бұл нұсқада шынайы аккаунт авторизациясы және серверлік дерекқорға сақтау әлі қосылмаған.
- Нәтиже тек осы құрылғы/браузерде сақталады; басқа құрылғыда көрінбейді.
- Сауалнама бастапқы өзін-өзі тануға арналған, валидтелген психологиялық диагностика немесе мамандыққа жарамдылық қорытындысы емес.
- Оқушылардың нақты жеке деректерін бұл демоға енгізбеңіз.
- Өндірістік іске қосу үшін Supabase Auth, серверлік рөл тексеруі, RLS аудиті, қауіпсіз Excel импорттау және резервтік көшіру қажет.

## Техникалық негіз
Next.js 14, React 18, TypeScript, Supabase клиент кітапханасы (әзірге қосылмаған).

## Supabase авторизациясын қосу (әкімші)
1. Supabase жобасында `supabase/SCHEMA_STARTER.sql` файлын SQL Editor арқылы бір рет орындаңыз.
2. Supabase → Authentication → Users → Add user арқылы әкімші email мен уақытша құпиясөзін жасаңыз.
3. `supabase/CREATE_FIRST_ADMIN.sql` ішіндегі `admin@school.kz` мәнін сол email-ге ауыстырып, SQL Editor-де орындаңыз.
4. Vercel → Project → Settings → Environment Variables бөлімінде мына екі айнымалыны Production, Preview және Development үшін қосыңыз:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY` (Supabase publishable/anon key)
5. Redeploy жасаңыз. Сайттағы `/login` бетіне әкімші email мен құпиясөзін енгізіп, «Әкімші» рөлін таңдаңыз.

**Қауіпсіздік:** `service_role` кілтін ешқашан `NEXT_PUBLIC_` айнымалысына салмаңыз және браузерге жарияламаңыз. Алғашқы әкімші аккаунтын тек сенімді адам жасауы керек. Қазіргі оқушылар беті мен панельдегі сандар әлі демо деректер; нақты CRUD және Excel импорт серверге қосылған жоқ.
