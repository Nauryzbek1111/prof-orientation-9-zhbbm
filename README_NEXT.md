# Профориентация 9 ЖББМ v0.3 — рөлдік кабинеттер

Бұл жаңарту әкімші, оқушы, сынып жетекшісі және психолог кабинеттерінің интерфейс қаңқасын қосады.

## Қосылған беттер
- `/admin` — әкімші панелі
- `/admin/students` — оқушылар базасының интерфейсі және файл таңдау батырмасы (әзірге демо, файлды импорттамайды)
- `/student` — оқушы кабинеті
- `/teacher` — сынып жетекшісі кабинеті
- `/psychologist` — психолог кабинеті

## Іске қосу
`npm install` → `.env.example` файлын `.env.local` деп көшіру → `npm run dev`

## Қазіргі шектеу
Бұл беттерде нақты Supabase Auth байланысы, деректерді оқу/жазу, нақты Excel парсері және рөлге қарай серверлік маршрут қорғауы әлі жоқ. Интерфейстерді өндірістік жүйе деп пайдаланбаңыз. Келесі әзірлеу кезеңінде серверлік авторизация, импортты валидациялау, аудит журналы және толық RLS тесттері қажет.
